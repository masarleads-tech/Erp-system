# بسيطة | Basita

نظام حسابات مطعم بسيطة: اليومية (المبيعات، الرواتب، المصاريف)، الدفعات، والتقارير اليومية والأسبوعية والشهرية مع تصدير Excel و PDF. بشتغل بدون إنترنت.

## التنزيل

نزّل آخر نسخة من صفحة **Releases**: ملف `Basita-Setup-x.x.x.exe`، شغّله، وبيطلع على سطح المكتب اختصار اسمه **Start ERP**.

البيانات بتنحفظ بـ `Documents\Basita` مع نسخة احتياطية يومية بـ `Documents\Basita\backups`.
